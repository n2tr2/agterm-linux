### Linux adaptations

- Move libghostty to `683d8db`, the revision upstream v0.39.1 pins.
  This brings the engine fixes for stale cursor and hyperlink references after a scroll clear (ghostty #13997), recycled row metadata (#14010), and DCS high bytes (#14016).
- Add the Kitty clipboard protocol (OSC 5522), with text reads and multi-representation writes, binary MIME types included.
  A refused clipboard prompt now returns the protocol's denial.
- Remove the Linux compatibility patch; upstream's mailbox teardown patch applies as is.
- Free each pane's GL objects under a retained reference to that pane's own GL context, instead of whichever context was current when the pane closed.
  A surface whose free has to be skipped stays pinned until process exit, and any degraded branch logs `agterm: retained GL context:`.

### Limitations

- Kitty image reads are not supported: reads serve text only, so an image-only read returns no image data.
- Kitty writes to PRIMARY are refused by the engine with `ENOSYS`; copy-on-select to PRIMARY still works.
- Hidden-surface GPU release is not enabled on Linux, so a hidden pane keeps its swap chain.
- On wlroots, an OSC 52 write with no input after another client's copy is lost with no error, so asynchronous and control-driven writes can fail silently.
  The previous engine pin behaves the same; Hyprland was not checked.
- A rare launch SIGSEGV inside `getenv` was seen on the previous pin and is not addressed here.
  Its cause is not established, and the late environment changes during startup that it may come from remain.
- A preedit stayed on screen after an IME commit under noble's ibus 1.5.29, also on the previous pin on Wayland; other ibus versions were not checked.

### Verification and compatibility

- Shared core: 4,795 tests in 214 suites passed.
  Linux package: 620 tests in 90 suites passed.
  Strict lint, Debug and Release builds, architecture, resources, and runtime-cache checks passed locally.
- The GTK suite has no clean pass on the final tree: the gate run went 62 of 63, with `remote-presentation` failing and no root cause found.
  None of 33 triage runs failed it, one of them a full 63 of 63, which does not clear the failure.
- OSC 52, OSC 5522, font size and scrollback, split resize, hide and reveal, IME commit, and busy and background teardown were exercised under headless sway and Xvfb, on GTK 4.14 and Mesa 25.2 with virtual input.
  Wayland GL was Intel hardware; plain X11 GL was llvmpipe.
- The GL teardown change was checked by tracing runs on Mesa and GTK 4.14: Wayland hardware GL, X11 software GL, and GLX.
  It was not tested on NVIDIA, Hyprland, GTK 4.22, or a real seat.
